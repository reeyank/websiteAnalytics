# Contributing

Thanks for your interest in contributing to websiteAnalytics!

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/reeyank/websiteAnalytics.git
   cd websiteAnalytics
   ```

2. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

3. Run the server:

   ```bash
   ./start_server.sh
   ```

## Pull Requests

1. Fork the repository and create a feature branch off `main`:

   ```bash
   git checkout -b my-feature
   ```

2. Make your changes and commit them with a clear message.
3. Push your branch and open a pull request against `main`.
4. Describe what your change does and why, and link any related issues.
5. Make sure your branch is up to date and wait for review.
